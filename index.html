Roadmap

The whole reading in one sentence

An active manager adds value by deviating from a benchmark (active weights). That active return is judged per unit of active risk (the information ratio), and the information ratio is produced by three things: skill (IC), breadth (BR) and how faithfully forecasts become positions (TC). The best manager for every investor is the one with the highest IR; each investor then dials the amount of active risk up or down by blending the manager with the benchmark.

Map of the reading — six steps, one chain
Read left → right, top → bottom: measure the value added, risk-adjust it, explain what produces it, use it to choose managers, apply it to strategies, and know where it breaks.

Module 35.1 · Value Added by Active Management
LOS 35.a

Measuring Value Added by Active Management

Describe how value added by active management is measured.

What "value added" means

Active management seeks to add value by outperforming a passively managed benchmark portfolio. Everything in this reading measures that outperformance — how big it is, where it came from, and how much risk was taken to get it.

Benchmark (passive reference portfolio)
→
Manager deviates from benchmark weights (active weights)
→
Return difference = active return (value added)

Choosing the benchmark: three qualities

An appropriate benchmark should satisfy all three:

🎯
1 · Representative

Represents the investment universe from which the active manager may choose.

🔁
2 · Replicable

Can be replicated at low cost (the passive alternative must be a real option).

🧾
3 · Verifiable

Weights are known beforehand (ex ante) and benchmark returns can be obtained promptly afterwards (ex post).

Slide The slide draws this as a tree: Choice of benchmark → representative / replicable / verifiable (ex ante or ex post).

Professor's Note — the beta assumption

In this reading we assume the systematic risk of the active portfolio equals that of the benchmark (beta of the active portfolio relative to the benchmark = 1). If the betas differ, active return is computed as the difference in risk-adjusted returns and is known as alpha.

Active return

Active return (RA) is the value added by active management. It can be measured ex ante (based on expectations) or ex post ("after the fact", realized returns).

Active return
RA = RP − RB   (ex post: realized returns)
E(RA) = E(RP) − E(RB)   (ex ante: expected returns)
RB = Σ wB,iRi     RP = Σ wP,iRi
Ri = return on security i
wB,i = benchmark weight of security i  ·  wP,i = portfolio weight of security i
N = number of securities (sums run i = 1 … N)

Active weights: where the value comes from

Active weight = a security's weight in the actively managed portfolio minus its weight in the benchmark. Overweighted securities have positive active weights, underweighted securities have negative active weights, and — because both sets of weights sum to 100% — active weights must sum to zero (not to 100%).

Active weight and active return
Δwi = wP,i − wB,i     ΣΔwi = 0
RA = ΣΔwiRi     (ex ante: E(RA) = ΣΔwiE(Ri))
RA = ΣΔwiRA,i   with  RA,i = Ri − RB (active security return)
Δwi = active weight of security i
RA,i = active security return: how much better or worse security i did than the benchmark as a whole

Slide Why can we subtract RB inside the sum? Because ΣΔwi = 0, we have ΣΔwiRB = RB × 0 = 0 — subtracting a constant from every security return leaves the answer unchanged. The two forms (total returns vs. active security returns) therefore always give the same RA.

💡Intuition: value is added only when the manager overweights securities that beat the benchmark and underweights those that lag it. Overweighting an under-performer — however confident the manager was — destroys value.
Worked example (Schweser) — ex-ante active return

An actively managed portfolio and its benchmark hold four securities. Calculate the ex-ante active return.

SecurityPortfolio weightBenchmark weightExpected return E(Ri)Active weight Δwi
A22%25%12%−3%
B20%25%−6%−5%
C21%25%4%−4%
D37%25%19%+12%

Method 1 — portfolio minus benchmark: E(RP) = 0.22(12) + 0.20(−6) + 0.21(4) + 0.37(19) = 9.31%; E(RB) = 0.25(12 − 6 + 4 + 19) = 7.25%; E(RA) = 9.31 − 7.25 = 2.06%.

Method 2 — active weights: E(RA) = (−0.03)(12) + (−0.05)(−6) + (−0.04)(4) + (0.12)(19) = −0.36 + 0.30 − 0.16 + 2.28 = 2.06%. Almost the entire gain comes from the +12% overweight in D, the best performer.

Several asset classes

With multiple asset classes (j = 1 … M), the expected returns on the portfolio and the benchmark are weighted averages, and ex-ante active return is the difference:

Active return with multiple asset classes
E(RP) = Σ wP,jE(RP,j)   and   E(RB) = Σ wB,jE(RB,j)
E(RA) = Σ wP,jE(RP,j) − Σ wB,jE(RB,j)
RP,j, RB,j = portfolio / benchmark return on asset class j
wP,j, wB,j = portfolio / benchmark weight of asset class j  ·  M = number of asset classes

Decomposing active return: asset allocation + security selection

Active return can alternatively be split into two parts:

🧭
1 · Asset allocation return

From deviations of asset-class portfolio weights from benchmark weights (the manager over/underweights whole asset classes).

🔍
2 · Security selection return

From active returns within asset classes (the manager's picks inside each class beat or lag that class's benchmark).

Decomposition of expected active return
E(RA) = ΣΔwjE(RB,j) + Σ wP,jE(RA,j)
E(RA,j) = E(RP,j) − E(RB,j)
ΣΔwjE(RB,j) = return from asset allocation: active weight × benchmark return of the class
ΣwP,jE(RA,j) = return from security selection: portfolio weight × active return within the class
E(RA,j) = expected active return within asset class j
💡Which weight goes where? Asset allocation uses the active weight (Δw) times the benchmark class return. Security selection uses the portfolio weight (wP) times the within-class active return. Memory hook: allocation = Δw × RB; selection = wP × RA.

Illustration (Schweser): a manager's benchmark is 25% stocks and 75% bonds. Overweighting stocks (and underweighting bonds) produces a return difference versus the benchmark — the asset allocation return. Holding a higher weight in a specific stock within the stock allocation (and correspondingly underweighting other stocks) contributes to the security selection return.

Worked example (Schweser) — Optoma Fund

Optoma invests in three asset classes. Calculate the expected active return and decompose it.

Module Quiz 35.1 — the logic behind the answer

  • Active weights add to zero, not 100%, and are measured against the benchmark weights — not against an equally weighted portfolio (unless the benchmark happens to be equally weighted).
  • Value added is positive only when end-of-period realized returns are positively correlated with the active weights chosen at the beginning of the period — i.e., the manager overweighted what went on to do well. This is the seed of the "correlation triangle" in LOS 35.c.
Key Concepts — LOS 35.a

Value added = active return = active portfolio return − benchmark return. Active return = Σ(active weight of security i × return of security i). Active return has two parts: asset allocation return + security selection return, E(RA) = ΣΔwjE(RB,j) + ΣwP,jE(RA,j).

Module 35.2 · The Information Ratio vs. the Sharpe Ratio
LOS 35.b

The Information Ratio and the Sharpe Ratio

Calculate and interpret the information ratio (ex post and ex ante) and contrast it to the Sharpe ratio.

Two ways to measure risk-adjusted return

The Sharpe ratio and the information ratio both measure risk-adjusted return, but they answer different questions: the Sharpe ratio asks "how much reward per unit of total risk, versus cash?"; the information ratio asks "how much reward per unit of active risk, versus the benchmark?".

Sharpe ratio (SR)
SR = (RP − RF) / σP
Numerator = excess return over the risk-free rate
Denominator = standard deviation of portfolio return (total risk)
  • SR is unaffected by the addition of cash or leverage. A 50% allocation to the risk-free asset cuts both the excess return and the standard deviation in half, so the ratio does not move.
  • A higher Sharpe ratio is better.

Why? Put weight w in a risky portfolio and 1 − w in cash: excess return = w(RP − RF) and risk = wσP, so SR = w(RP − RF) / (wσP) — the w cancels. This is why risk-averse and aggressive investors can hold the same risky portfolio and differ only in how much cash/leverage they use.

Worked example (slide Example 7) Slide — adjusting risk with cash

The risk-free rate is 3%. Portfolio A: expected return 11.0%, volatility 14.3%, Sharpe 0.559. Portfolio B: expected return 14.2%, volatility 21.9%, Sharpe 0.511.

1. Cash needed to bring B's risk down to A's. Weight in B = σP/σB = 14.3/21.9 = 65.3%; weight in cash = 100% − 65.3% = 34.7%.

2. Sharpe ratio of the B + cash mix: unaffected by cash → still 0.511.

3. Expected return of the mix: 0.653 × 14.2% + 0.347 × 3.0% = 10.31%. Re-check: (10.31 − 3.0)/14.3 = 0.511 ✓.

Conclusion: at the same risk (14.3%) Portfolio A earns 11.0% against 10.31% for the B + cash mix — consistent with A's higher Sharpe ratio (0.559 vs 0.511). Cash can rescale risk, but it can never repair a lower Sharpe ratio.

🧮 Cash and leverage: Sharpe stays put, information ratio moves

The information ratio (IR)

The information ratio is the ratio of the active return to the standard deviation of the active returns, which is known as active risk or benchmark tracking risk.

Information ratio (IR)
IR = (RP − RB) / σ(RP−RB) = RA / σA = active return / active risk
σ(RP−RB) = σA = standard deviation of the differences between portfolio and benchmark returns (tracking risk) — not σP
In this reading the IR is usually the ex-ante IR (based on expectations); it can also be applied ex post to realized returns
Sharpe ratioInformation ratio
NumeratorRP − RF (excess return over cash)RP − RB (active return over the benchmark)
DenominatorσP — total (absolute) riskσA — active risk (tracking risk)
Reward per unit of…absolute riskrisk in benchmark-relative terms
Effect of adding cash / leverageNone — unchangedChanges (adding cash tends to lower it)
Typical useJudging the total portfolio against the risk-free assetJudging a manager's skill against a benchmark

Some important points about the IR

  • Ex ante IR is generally positive (otherwise active management is not worth pursuing), while ex post IRs will often turn out to be negative — the manager underperformed the benchmark.
  • Closet index fund: purports to be active but closely tracks the benchmark. It has a Sharpe ratio similar to the benchmark's, a very low IR (often negative after fees) and little active risk.
  • Market-neutral long-short equity fund (β = 0) using the risk-free rate as its benchmark: IR = SR. Active return equals portfolio return minus the risk-free rate, and active risk equals total risk.
  • Unlike SR, the IR changes with the addition of cash or leverage. The numerator is measured against a non-cash benchmark: adding cash lowers active return while active risk barely changes, so the IR most likely decreases.
  • Aggressiveness does not matter for an unconstrained active portfolio: triple the active weights and active return and active risk both triple, so the IR is unchanged.
  • Blending with the benchmark leaves the IR unchanged: increasing the benchmark weight shrinks active return and active risk proportionally.
  • Investors choose their active risk by splitting money between the active portfolio and the benchmark. Example: a fund has 10% active risk; an investor who wants only 6% invests 60% in the fund and 40% in the benchmark.
💡Memory hook: Sharpe = total risk, cash-proof. IR = active risk, benchmark-proof. Scaling the active bets (×3), or blending with the benchmark, scales return and risk together — IR is immune. Mixing with cash breaks the IR but not the SR.

Constructing the optimal portfolio

For an unconstrained active portfolio, the optimal amount of active risk is the level that maximizes the portfolio's Sharpe ratio. Slide Think of it as combining the benchmark portfolio with the actively managed portfolio to build the optimal portfolio.

Benchmark + active portfolio → optimal portfolio
Optimal active risk, Sharpe ratio and total risk of the optimal portfolio
σA* = (IR / SRB) × σB
SRP = √(SRB² + IR²)   ⇔   SRP² = SRB² + IR²
σP² = σB² + σA²
σA* = optimal amount of active risk  ·  IR = information ratio of the active portfolio
SRB = Sharpe ratio of the benchmark  ·  σB = standard deviation of the benchmark return
Professor's Note

Unconstrained active portfolios have optimal weights for each security, based on ex-ante expectations of active return and active risk. Sometimes constraints (e.g., long-only) are imposed, giving less-than-optimal weights. We discuss this under the transfer coefficient (LOS 35.c).

Read the formulas: a higher IR raises both the optimal active risk and the Sharpe ratio; a stronger benchmark (higher SRB) lowers the active risk you need; and the active risk is measured relative to the size of the benchmark risk (σB). Since SRP² = SRB² + IR², every unit of IR adds to the Sharpe ratio in quadrature, and the portfolio with the highest IR therefore has the highest SR — the link used in LOS 35.d.

Worked example (Schweser + slide Example 8) — Omega Fund

Omega has an information ratio of 0.2 and active risk of 9%. The benchmark has a Sharpe ratio of 0.4 and total risk of 12%. Portfolio P combines Omega and the benchmark with an optimal level of active risk. Calculate:

1. Optimal active risk and Portfolio P's Sharpe ratio. σA* = (0.2/0.4)(12%) = 6%. SRP = (0.4² + 0.2²)½ = √0.20 = 0.4472.

2. Portfolio P's excess return. E(RA) = IR × σA = 0.2 × 6% = 1.2% = RP − RB. From SRB = (RB − RF)/σB: 0.40 = (RB − RF)/0.12 → RB − RF = 4.8%. So excess return = (RP − RB) + (RB − RF) = 1.2% + 4.8% = 6.0%; σP² = 0.12² + 0.06² = 0.018 → σP = 13.4%. Check: SR = 6.0/13.4 = 0.4472 ✓.

3. Proportions. Optimal active risk 6% ÷ Omega's active risk 9% = 67% Omega, 33% benchmark.

Module Quiz 35.2 — the logic behind the answer

The information ratio can be applied either ex ante (to expected returns) or ex post (to realized returns). The Sharpe ratio measures reward per unit of absolute (total) risk; the information ratio measures reward per unit of risk in benchmark-relative terms.

Key Concepts — LOS 35.b

SR = (RP − RF)/σP. IR = (RP − RB)/σ(RP−RB) = RA/σA. Unconstrained portfolio optimal active risk: σA* = (IR/SRB)σB. The Sharpe ratio of a portfolio made of the optimal proportion of benchmark and active portfolio is SRP = √(SRB² + IR²).

Module 35.3 · The Fundamental Law
LOS 35.c

The Fundamental Law of Active Portfolio Management

Describe and interpret the fundamental law of active portfolio management, including its component terms — transfer coefficient, information coefficient, breadth, and active risk (aggressiveness).

Three factors determine the information ratio

🧠
Information coefficient (IC)

A measure of the manager's skill: how well forecasts of active return line up with what actually happens.

🔌
Transfer coefficient (TC)

How faithfully forecasts are transferred into active weights — reduced by constraints (long-only, limits on active risk).

🎲
Breadth (BR)

The number of independent active bets taken per year — how often the skill gets used.

A fourth element, active risk σA ("aggressiveness"), does not change the IR but scales the expected active return: E(RA) = IR × σA. Slide The slide's wheel shows all four: IC = security-forecasting skill, TC = portfolio-construction ability, BR = independent investment decisions per year, aggressiveness = benchmark tracking risk — together producing expected value added.

The four ingredients of expected value added Slide

Information coefficient (IC)

IC is the ex-ante (expected), risk-weighted correlation between active returns and forecasted active returns. The ex-post information coefficient, ICR, measures the actual correlation between active returns and the expected (forecast) active returns. IC is the part of the process that is the manager's own skill.

Transfer coefficient (TC)

TC can be thought of as the correlation between actual active weights and optimal active weights. The optimal active weight of a security is positively related to its expected active return and negatively related to its expected active risk.

  • Unconstrained active portfolio: actual weights = optimal weights → TC = 1.
  • Constrained portfolio (e.g., constraints on short positions or on active risk): actual weights differ from optimal weights → TC < 1.
Transfer coefficient (cross-sectional correlation, risk-adjusted)
TC = CORR( μi/σi , Δwiσi ) = CORR( Δwi*σi , Δwiσi )
μi = ex-ante active return forecast for security i  ·  σi = forecast volatility of the active return on security i
Δwi = actual active weight  ·  Δwi* = optimal active weight

Breadth (BR)

Breadth is the number of independent active bets taken per year. Example: a manager who takes active positions in 10 securities each month has BR = 10 × 12 = 120 — if those 120 decisions are truly independent (see LOS 35.f).

The correlation triangle Slide

Three quantities, three correlations
  • Forecasts → active weights (left edge): the transfer coefficient — portfolio-construction ability.
  • Forecasts → realized active returns (right edge): the information coefficient — signal quality (skill).
  • Active weights → realized active returns (bottom edge): value added — the payoff that results when good signals (IC) are turned into positions faithfully (TC).
💡Memory hook: IC = how good is the forecast; TC = how well is the forecast turned into weights; BR = how many times per year; σA = how big the bets are. The chain breaks at the weakest link — a brilliant forecast (high IC) squeezed through tight constraints (low TC) still delivers a low IR.

The Grinold rule

The Grinold rule converts skill into a forecast of active return for each security, from the information coefficient, the security's active risk and a standardized score.

Grinold rule and expected value added
μi = IC × σi × Si
E(RA) = Σ Δwiμi
Δwi* = (μi / σi²) × ( σA / (IC × √BR) )    Slide
μi = active return forecast for security i  ·  IC = information coefficient
σi = forecast volatility of the active return on security i
Si = score of security i, standardized with an assumed variance of 1 (e.g., +1 = expect outperformance, −1 = expect underperformance)
Δwi* = optimal active weight  ·  σA = active portfolio risk  ·  BR = independent decisions per year

Slide Read the weight formula: the optimal active weight rises with the forecast per unit of variance (μi/σi²) — high forecast, low volatility → big bet — and the whole set of weights is scaled by σA/(IC√BR) so that the portfolio hits the chosen active risk.

Worked example (slide Example 9) Slide — Grinold rule

Four securities have uncorrelated active returns with volatilities of 25% and 50%. The investor expects the first two to outperform and the last two to underperform, assigning scores of +1 and −1:

SecurityScore SiVolatility σi
#1+1.025.0%
#2+1.050.0%
#3−1.025.0%
#4−1.050.0%

1. Forecast active returns with IC = 0.20: μi = IC × σi × Si → #1: 0.20 × 25% × 1 = +5%; #2: 0.20 × 50% × 1 = +10%; #3: −5%; #4: −10%.

2. Breadth: four securities with uncorrelated active returns and forecasts independent from year to year → BR = 4.

3. Optimal active weights for σA = 9.0%: σA/(IC√BR) = 0.09/(0.20 × 2) = 0.225. #1: (0.05/0.25²)(0.225) = 0.8 × 0.225 = +18%; #2: (0.10/0.50²)(0.225) = 0.4 × 0.225 = +9%; #3: −18%; #4: −9%. Note the lower-volatility securities get the larger bets, and the active weights sum to zero.

The basic fundamental law (unconstrained portfolio, TC = 1)

Basic fundamental law
IR* = IC × √BR
E(RA)* = IC × √BR × σA
σA* = (IR / SRB) × σB
SRP² = SRB² + IR²
Asterisks (*) denote optimal values for an unconstrained portfolio (TC = 1)
IR* is the maximum information ratio the strategy can achieve with its skill and breadth
Diminishing returns to breadth: IR* = IC × √BR Study aid
The square root matters: quadrupling breadth only doubles the IR (IC = 0.10: BR 25 → IR 0.50; BR 100 → IR 1.00). Skill (IC) scales IR one-for-one; breadth only by its square root.

The full fundamental law (constrained portfolio, TC < 1)

For constrained portfolios the actual active weights (Δwi) differ from the optimal active weights (Δwi*), so TC < 1.

Full fundamental law
IR = TC × IC × √BR
E(RA) = TC × IC × √BR × σA
σCA* = TC × (IR* / SRB) × σB
SRPC² = SRB² + TC² × IR*²
σCA* = optimal active risk of the constrained portfolio  ·  IR* = IR of the unconstrained portfolio
SRPC = Sharpe ratio of the constrained optimal portfolio
Basic law (TC = 1)Full law (TC < 1)
Information ratioIR* = IC√BRIR = TC × IC√BR  <  IR*
Expected active returnE(RA)* = IC√BR σAE(RA) = TC × IC√BR σA  <  E(RA)*
Optimal active riskσA* = (IR*/SRB)σBσCA* = TC(IR*/SRB)σB  <  σA*
Sharpe ratio of optimal portfolioSRP = √(SRB² + IR*²)SRPC = √(SRB² + TC²IR*²)  <  SRP

Because TC < 1: the information ratio must be lower than the optimal IR* (IR < IR*), the expected active return must be lower than the optimal E(RA)*, the optimal active risk of a constrained portfolio is lower than that of an unconstrained portfolio, and its Sharpe ratio is lower too. Constraints cost you on every line.

Worked example (slide Example 10) Slide — basic fundamental law

Four securities have uncorrelated active returns and forecasts that are independent from year to year. The benchmark is equally weighted (wB,i = 25% each) and its forecast return is 10.0%.

2. Forecast total and active return of the managed portfolio. E(RP) = 0.43(15) + 0.34(20) + 0.07(5) + 0.16(0) = 6.45 + 6.80 + 0.35 + 0 = 13.6%; E(RA) = 13.6% − 10.0% = 3.6% (check: ΣΔwiμi = 0.9 + 0.9 + 0.9 + 0.9 = 3.6%).

3. Active risk. σA² = ΣΔwi²σi² = 2(0.18² × 0.25²) + 2(0.09² × 0.50²) = 2(0.002025) + 2(0.002025) = 0.0081 → σA = 9.0%.

4. Breadth, with IC = 0.20. E(RA) = IC√BR σA → 3.6% = 0.20 × √BR × 9% → √BR = 2 → BR = 4 (the four independent securities — consistent with Example 9).

Ex-post performance measurement

Realized value added is the ex-post active return the manager actually achieves. Using the realized information coefficient ICR, the fundamental law becomes a conditional expectation, and the actual return is that expectation plus noise:

Ex-post fundamental law
E(RA | ICR) = TC × ICR × √BR × σA
RA = E(RA | ICR) + noise
ICR = realized information coefficient  ·  RA = actual active return
E(RA | ICR) = expected value added given the realized skill of the investor that period
Noise = constraint-induced noise: the effect of constraints that impinge on the optimal portfolio structure

The proportion of realized active-return variance (σA²) attributed to variation in the realized IC (forecasting success) is TC². The remaining (1 − TC²) is attributed to constraint-induced noise. Example: TC = 0.8 → 64% skill, 36% noise.

Worked example (slide Example 11) Slide — ex-post performance

A strategy has expected IC = 0.05, BR = 100, TC = 0.80 and annualized active risk σA = 4.0%.

1. Expected value added: TC × IC × √BR × σA = 0.80 × 0.05 × 10 × 4.0% = 1.6%.

2. Realized IC = −0.10, zero noise: 0.80 × (−0.10) × 10 × 4.0% = −3.2%.

3. Actual active return = −2.6%. RA = E(RA | ICR) + noise → −2.6% = −3.2% + noise → noise = +0.6%: the constraint-induced noise offset 0.6 percentage points of the forecast loss.

4. Variance attribution: TC² = 0.64 → 64% of the variation in performance comes from variation in the realized IC; 36% (1 − 0.64) from constraint-induced noise.

What is — and is not — in the investor's control (Module Quiz 35.3 Q1)

Investors constrained by regulation or investment policy may find that several elements of the fundamental law are out of their hands: the transfer coefficient, the breadth of the strategy and the benchmark tracking risk can all be dictated by policy. The element most likely to remain within the manager's control is the information coefficient — it represents the manager's own skill and ability to forecast returns accurately.

Key Concepts — LOS 35.c

The three components of the IR: information coefficient (skill), breadth (number of independent active bets) and transfer coefficient (degree of constraints). IR = (TC) IC √BR and E(RA) = (TC) IC √BR σA. For an unconstrained portfolio, TC = 1.

Manager Selection and the Level of Active Risk

Explain how the information ratio may be useful in investment manager selection and choosing the level of active portfolio risk.

The portfolio-theory background

Portfolio theory says investors choose some combination of the risk-free asset and an optimal risky portfolio, with the mix set by their preferences (risk tolerance). The optimal risky portfolio is the one with the highest Sharpe ratio.

Optimal risky portfolio = highest Sharpe ratio
→
SR of an active portfolio exceeds the benchmark's by its IR: SRP² = SRB² + IR²
→
Highest IR ⇒ highest SR

The manager-selection rule

Because the Sharpe ratio of the blended portfolio rises with the IR, the actively managed portfolio with the highest information ratio is the optimal (active) portfolio for all investors, regardless of their risk tolerance. Investors therefore choose the manager with the highest IR — the manager with the highest level of skill — and then dial their own risk up or down:

  • A risk-averse investor holds less of the manager and more of the benchmark (or cash).
  • A risk-tolerant investor holds more of the manager.
  • Both pick the same manager; only the amount of active risk differs. Risk tolerance determines the size of the allocation, never the identity of the manager.
💡Common trap: the manager with the highest expected active return is not necessarily the best. A manager returning 4% on 10% active risk (IR = 0.40) loses to one returning only 2.4% on 4% active risk (IR = 0.60) — the second can be scaled up or blended in whatever size the investor wants, with a higher Sharpe ratio at every risk level.

Choosing the level of active risk

The IR gives the expected active return for a target level of active risk:

Expected active return for a given active risk
E(RA) = IR × σA
Example: IR = 0.40 and the investor accepts σA = 5% → E(RA) = 0.40 × 5% = 2.0%
The investor reaches σA by blending the manager with the benchmark (LOS 35.b); the best σA is σA* = (IR/SRB)σB

Key Concepts — LOS 35.d

An investor will always choose the active manager with the highest information ratio, regardless of her risk aversion. She then combines this optimal active portfolio with the benchmark to create a portfolio with a level of risk suited to her risk preferences.

Market Timing, Security Selection and Sector Rotation

Compare active management strategies, including market timing and security selection, and evaluate strategy changes in terms of the fundamental law of active management.

Market timing

Market timing is simply a bet on the direction of the market (or a segment of the market). For example, an active manager may rotate money out of equities and into cash because stock prices are expected to fall. For a market timer, IC is based on the proportion of correct calls:

Information coefficient of a market timer
IC = % correct − % incorrect = 2 × (% correct) − 1
If the manager is right 50% of the time, IC = 0 (no skill: a coin flip)
Breadth = number of independent calls per year: quarterly decisions → BR = 4; monthly → BR = 12
Worked example (Schweser + slide Example 12) — market timer vs. security selector

Darsh Bhansali (Optimus Capital), a market timer, makes quarterly asset-allocation decisions and is right 55% of the time. Mike Neal, a security selector, makes 50 active stock selections a year with an information coefficient of 0.04. Compute their information ratios assuming unconstrained portfolios.

Both are unconstrained, so TC = 1 and IR = IC√BR.

Bhansali: IC = 2(0.55) − 1 = 0.10; BR = 4 → IR = 0.10 × √4 = 0.20.

Neal: IC = 0.04; BR = 50 → IR = 0.04 × √50 = 0.28.

Lesson: Neal has much less skill per bet (0.04 vs 0.10) yet the higher IR, because he makes far more independent bets. Breadth can compensate for modest skill.

Sector rotation

Sector rotation is market timing applied across sectors: the manager overweights sectors expected to outperform and underweights sectors expected to underperform. Take a two-sector market (sectors X and Y) with expected returns E(RX), E(RY) and volatilities σX, σY, and correlation rXY. The active risk of the strategy is the standard deviation of the differential return of the two sectors (RX − RY), written σC:

Sector-rotation active risk and return
σC = [ σX² − 2σXσYrXY + σY² ]½ = σ(RX−RY)
annualized active risk = σA = σC × √BR
annualized active return = E(RA) = IC × √BR × σA
σC = active risk of one rotation decision (per period)  ·  rXY = correlation of the sector returns
BR = number of allocation bets per year (monthly → 12; quarterly → 4)
IC for the rotator = 2(% correct) − 1

Read σC: it is the usual two-asset spread formula. The higher the correlation between the sectors, the smaller σC (the sectors move together, so rotating between them is less risky); at r = 1 and equal volatilities it is zero.

Worked example (Schweser + slide Example 13) — Hwang Soi's sector rotation

Soi makes monthly allocation decisions between consumer discretionary and consumer staples. The historical correlation of the two sectors is 0.30 and Soi's bets have been correct 60% of the time.

SectorE(R)σBenchmark weight
Consumer staples10.8%3.0%65%
Consumer discretionary13.2%5.0%35%

1. Annualized active risk. Monthly σC = [0.03² − 2(0.03)(0.05)(0.30) + 0.05²]½ = [0.0009 − 0.0009 + 0.0025]½ = 0.05 (5%). Annualized: 5% × √12 = 17.32%.

2. Expected annualized active return. IC = 2(0.60) − 1 = 0.20. E(RA) = 0.20 × √12 × 17.32% = 12%. Alternative: probability-weighted monthly active return = 0.60(+5%) + 0.40(−5%) = 1% per month → 1% × 12 = 12%.

3. Allocation when active risk is limited to 5.20%. The deviation from benchmark weights is limited to 5.20% / 17.32% = 30%. If Soi expects staples to outperform: staples = 65% + 30% = 95%, discretionary = 35% − 30% = 5%.

Why the limit divides by σC: shifting Δ out of one sector and into the other earns Δ × (RX − RY), so its active risk is Δ × σC; capping risk at 5.20% therefore caps Δ at 5.20% / σC.

Strengths and Limitations of the Fundamental Law

Describe the practical strengths and limitations of the fundamental law of active management.

Strengths

The fundamental law can be used to evaluate the potential value added of a range of active strategies — security selection, market timing and sector rotation — and it separates expected value added into the contributions of a few basic elements (IC, BR, TC and σA). That is exactly why it is useful: it tells the manager where to improve.

Limitations: "garbage in, garbage out"

The practical limitation is summarized as "garbage in, garbage out": poor input estimates lead to incorrect evaluations. In unconstrained optimization, the two inputs that determine the IR are (1) the information coefficient (IC) and (2) the breadth (BR). The limitations come from inaccurate estimates of those two inputs:

🪞
1 · Ex-ante measurement of skill

IC is an estimate of the accuracy of the manager's forecasts before the fact. Managers tend to overestimate their ability to outperform, hence they overestimate IC — and the ex-ante IR is only as accurate as the IC.

🔗
2 · Independence of decisions

BR is meant to count truly independent decisions. If two or more decisions rely on the same (or similar) information, they are not independent, and the nominal count of decisions overstates breadth.

Breadth when decisions are correlated
BR = N / [ 1 + (N − 1)ρ ]
N = number of decisions (securities)  ·  ρ = average correlation between the decisions (active security returns)
ρ = 0 → BR = N (all independent)  ·  ρ = 1 → BR = 1 (really one big bet)

Numeric feel: N = 50 securities with average correlation ρ = 0.20 → BR = 50 / (1 + 49 × 0.20) = 50 / 10.8 = 4.63 — not 50. Using 50 would overstate the IR by √(50/4.63) ≈ 3.3×.

🧮 Effective-breadth lab — how correlation shrinks breadth and the IR

Two ways independence breaks down

↔️
Cross-sectional dependency

Decisions across securities at the same time share a common driver. E.g., an investor forecasts outperformance of all the stocks in one industry and underperformance of all the stocks in another; or a value strategy applied to stocks in the same industry (most have similar fundamentals such as P/E). They are really one bet.

⏳
Time-series dependency

Decisions on the same security across time repeat the same view. E.g., a stock forecast to outperform this month is likely to keep the forecast for several months in a row; monthly rebalancing decisions are not truly independent from period to period.

Module Quiz 35.4 — the logic behind the answers

  • Breadth = number of securities × number of decision periods per year only if (1) active returns are cross-sectionally uncorrelated and (2) active returns are uncorrelated over time. Correlation in either dimension reduces breadth.
  • The law's usefulness comes from separating value added into the contributions of a few basic elements — so "attribution of value added to a small number of inputs" is a strength, not a limitation. The real limitations concern uncertainty about the ex-ante IC and the definition of breadth as independent decisions.
Key Concepts — LOS 35.f

While the fundamental law can evaluate market timing, security selection and sector rotation, be aware of its practical limitations: bias in the measurement of the ex-ante information coefficient and lack of true independence when measuring the breadth of an active strategy.
